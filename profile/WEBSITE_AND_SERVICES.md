## Services

**Voice DNA setup (assisted)**
A guided session to install Voice DNA, build your voice profile from writing you own, calibrate it, and produce your first checked draft. You keep the profile, voice guide and handoff. *Early access; price to be set.*

**AI workflow design**
For a team that wants one repeatable AI workflow (proposals, reports, client updates): we map the stages, the records each produces, who approves what, and where facts come from, then build it as a Claude Skill or on an MCP server. You get the workflow, its tests and an operator handoff. *Scope and price agreed per project.*

**AI implementation review**
A review of an existing AI workflow against the failures that cost trust: invented details, untraced numbers, approvals that don't match what was reviewed, work that can't be resumed. You get a written list of findings, ranked, with the smallest fix for each. *Scope and price agreed per project.*

Not offered: legal, tax or financial advice; hosted software with user accounts (not built yet); guaranteed outcomes.
