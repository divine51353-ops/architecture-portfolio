## Relevant industry patterns

### Enterprise AI governance
Maps to policy-first and bounded-execution approaches used in enterprise AI and responsible AI design.

### Multi-agent workflow systems
Maps to modern agent orchestration using separate offices, structured outputs, and explicit routing.

### Product architecture
Maps to software product-family design where one architectural standard supports multiple market-facing applications.

### Knowledge-backed applications
Maps to retrieval-backed systems using files, state, and typed outputs rather than generic chat responses.
