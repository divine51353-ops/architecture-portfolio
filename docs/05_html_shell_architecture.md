# HTML Shell Architecture

## Summary

The shell approach used in this portfolio turns AI products from document kits into operator-facing browser studios.

## Principles

- local-first where possible
- BYOK for cost control
- room-based navigation
- governed outputs
- branded surface instead of generic chat

## Why shell architecture matters

A shell changes how buyers experience the system:

- from instructions to a software surface
- from setup burden to direct operation
- from raw prompts to product environment

## Commercial impact

This supports:

- faster deployment
- lower infrastructure burden in early stages
- stronger packaging
- cleaner white-label and install paths
