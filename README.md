# Architecture Portfolio

A public-facing portfolio repository for governed AI architecture, multi-agent workflow design, and vertical AI product systems.

This repository presents the professional, market-readable layer of a larger protected architecture library. It is designed to show systems thinking, workflow design, productization logic, and technical implementation direction without exposing protected source doctrine.

## What this repository demonstrates

- Governed AI architecture and pre-output governance concepts
- Multi-agent workflow design for writing, compliance, and media systems
- HTML shell product architecture using BYOK delivery patterns
- Python implementation direction for modular intelligence systems
- Product-family design across creative, compliance, and operator-facing domains

## Featured systems

### 1. Governed Intelligence Architecture
A constitutional governance framework for building AI systems as coherent product families instead of isolated prompts or one-off agents.

### 2. Narrative Continuity Engine
A long-form narrative system designed to preserve continuity, story identity, payoff integrity, and emotional control across chapters and sessions.

### 3. CineRuntime Studio
A cinematic governance runtime for scene planning, franchise continuity, visual DNA inheritance, routing, validation, and pipeline packaging.

### 4. Agent Workflow Architecture
Production-oriented multi-agent workflow designs for:
- Book Forge Studio
- CIVITAS nonprofit workflow
- Brand intelligence systems

### 5. HTML Shell Product Architecture
Local-first, BYOK browser studios designed as governed operator surfaces rather than generic chat interfaces.

This repository is intentionally public-safe.

Included:
- architecture summaries
- market-readable translations
- workflow maps
- diagrams
- product-family documentation

Excluded:
- protected source doctrine
- proprietary internal naming dependencies where not needed
- licensing internals
- derivative-rights logic
- private operator artifacts
- full protected runtime constitutions
